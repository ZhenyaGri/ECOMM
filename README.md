# E-Commerce Project  

**Welcome to our online furniture store!** This is a modern eCommerce platform where users can browse, select, and purchase high-quality furniture from the comfort of their home. The application is built using React, TypeScript, and CSS. The platform provides an enjoyable shopping experience.

## Key Features  
- Browse products with filters and search  
- Add items to cart and checkout  
- User authentication (login/registration)  
- Responsive design 

## Tech Stack
- TypeScript
- React
- Vite
- Vitest
- CSS
